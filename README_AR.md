# EGX Investor Flow Collector

تطبيق/لوحة ويب لمتابعة تداولات **أسهم فقط** حسب الفئات الست: الأفراد والمؤسسات × مصريين وعرب وأجانب.

## الحالة الفعلية المهمة

**هذا إصدار أولي (غير مُعايَر على الصفحة الحية).** موقع EGX أعاد خطأ 502 أثناء فحصه، لذلك لم نتمكن من التحقق من أسماء العناصر أو بنية جدول البيانات أو تاريخ الجلسة الظاهر. لا توجد بيانات فعلية مخترعة في الملفات.

- السكربت يفتح صفحة البورصة باستخدام Chromium (Playwright).
- يحاول تحديد «أسهم فقط» **بالاسم الصريح**.
- لا يكتب أي صف إلا إذا وجد جدولًا يحمل عناوين «شراء» و«بيع»، والفئات الست كاملة؛ يسجل خطأ بدل أرقام تخمينية.
- حالياً يحتاج التحقق مرة واحدة من عناصر الصفحة، خصوصًا إذا كانت المعطيات معروضة في رسوم بيانية لا جداول HTML.
- نظام تشغيل GitHub Actions مُعدّ يوميًا الساعة 5:30 مساءً بتوقيت القاهرة في أيام التداول المعتادة (الأحد إلى الخميس). **قد تتأخر المهام المجدولة بسبب خدمة GitHub**.
- ملف Excel/CSV يُحدث فقط بعد استخراج ناجح، ويستبعد تاريخ الجلسة المكرر.
- احتياطًا: يجب إضافة تحقق من تاريخ جلسة EGX الظاهر قبل تشغيل النظام دون متابعة؛ إدخال تاريخ التشغيل الحالي لا يثبت أن البيانات تخص اليوم (خاصة العطلات).

## اختبار محلي (Windows)

1. ثبّت Python 3.11 أو أحدث.
2. في مجلد المشروع:
   ```bash
   pip install -r requirements.txt
   python -m playwright install chromium
   python collector.py --diagnostic --headed
   ```
3. لو فشل، افتح `diagnostics/latest.png` و `diagnostics/latest.html` و `diagnostics/tables.json` (إن وُجد). ستحتاج تعديل التعرف على محدد «أسهم فقط» والجدول حسب شكل الصفحة الحقيقي.
4. بعد معايرة محدد النطاق واستخراج القيم، اختبر التشغيل بتاريخ جلسة موثوق:
   ```bash
   python collector.py --date 2026-11-16
   ```
5. افتح `docs/index.html` باستخدام خادم محلي، أو فعّل GitHub Pages. ملف Excel في `data/investor_flows.xlsx`.

## تشغيل تلقائي بدون إبقاء الكمبيوتر يعمل

1. ارفع **محتويات** هذا المجلد إلى مستودع GitHub خاص أو عام (راعِ إعدادات نشر GitHub Pages: المواقع المنشورة تكون عادة عامة حتى لو المشروع خاص وفق الخطة).
2. فعّل Settings → Actions → General → Workflow permissions → Read and write permissions.
3. جرّب Actions → EGX Daily Investor Collection → Run workflow؛ راقب logs وتشخيص الخطأ.
4. بعد التأكد من الاستخراج وتاريخ الجلسة، فعّل Pages → Deploy from a branch → main → `/docs`.
5. الرابط المنشور عبارة عن لوحة قراءة؛ جمع البيانات يتم في GitHub Actions لا من متصفح الزائر.

## هيكل Excel

صف واحد لكل جلسة؛ التاريخ، نطاق الأسهم فقط، عنوان المصدر، وقت الجمع، ثم لكل واحدة من الفئات الست: Buy, Sell, Net. **الوحدة الرقمية كما تظهر في المصدر**، ولا نفترض جنيه/مليون جنيه إلا بعد مراجعتها.

## حدود معروفة

- الرسم البياني بدون جدول مفصل يستلزم معايرة استخراج بياناته من المصدر الشبكي أو مكتبة الرسم.
- إذا كان الموقع يمنع متصفحات مراكز البيانات فقد يفشل GitHub Actions؛ يلزم جهاز/خادم يستطيع الوصول إلى الموقع.
- إذا أغلق السوق لعطلة، قد تعرض الصفحة جلسة قديمة. يجب منع وضع تاريخ اليوم على هذه البيانات بتأكيد تاريخ الجلسة من الموقع. لهذا لا يُعتبر التشغيل المجدول جاهزًا للاعتماد المالي قبل معايرته.
- لا ينبغي تجاوز وسائل الحماية أو قيود الاستخدام في الموقع.
